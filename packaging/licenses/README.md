# Third-party licences

Kogen's release archive bundles third-party software. The licence texts ship in the archive's `licenses/` folder, and `install.sh` installs them with the program.

| Component | Version | How it is bundled | Licence | Source of these texts |
| --- | --- | --- | --- | --- |
| Erlang/OTP (ERTS and the applications the release uses) | 29.1.1 | the Elixir release in `lib/release/` | Apache-2.0, plus the licences of code OTP itself includes (`erlang-otp/LICENSES/`), and the notices of the IETF, RSA and Ericsson BSD-licensed modules compiled into `public_key` (`erlang-otp/components/public_key-notices.md`) | `LICENSE.txt` and `LICENSES/` of github.com/erlang/otp, tag `OTP-29.1.1` |
| Code ERTS includes: asmjit, PCRE2, Ryū, Zstandard | as in OTP 29.1.1 | compiled into ERTS | Zlib (asmjit), BSD-3-Clause WITH PCRE2-exception (PCRE2), Apache-2.0 or Boost (Ryū), BSD-3-Clause or GPL-2.0 (Zstandard, used under BSD) | `erlang-otp/components/`, from `erts/emulator/{asmjit,pcre,ryu,zstd}` of tag `OTP-29.1.1` |
| OpenSSL | 3.5.8 | compiled into Erlang/OTP's `crypto` on macOS; the Linux archive uses the system `libcrypto` | Apache-2.0 | `openssl/LICENSE.txt`, tag `openssl-3.5.8` |
| Elixir (`elixir`, `logger`, `iex`) | 1.20.4 | the Elixir release in `lib/release/` | Apache-2.0; Unicode data licence for the Unicode tables compiled into Elixir; Elixir trademark policy (`elixir/LICENSES/`) | `LICENSE` of the Elixir 1.20.4 install, `LICENSES/` of github.com/elixir-lang/elixir, tag `v1.20.4` |
| Go standard library and runtime | 1.27 | linked into `bin/kogen` | BSD-3-Clause (`go/LICENSE`), patent grant (`go/PATENTS`) | `LICENSE` and `PATENTS` of the Go 1.27.2 distribution |
| `@informalsystems/quint` and its npm dependencies | 0.33.0 | `lib/quint/node_modules/` | per package: `npm-packages.md`, each package's own licence file inside `node_modules`, or `npm/` for the packages that ship none | generated by `packaging/package.sh` from the installed packages |
| `@cucumber/cucumber` and its npm dependencies | 13.3.0 | `lib/cucumber/node_modules/` | per package, as above | as above |

Node.js is not in the archive. When no Node 22 or newer is on `PATH`, `install.sh` downloads the current Node LTS from nodejs.org into Kogen's folder, and that distribution carries its own `LICENSE`.
