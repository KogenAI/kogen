description: Create a feature summary document for designers and stakeholders
---

Analyze current feature impl and create clear markdown summary for designers and product managers.

Document structure (exactly these sections):

- **Summary** — short paragraph describing what feature does from user perspective
- **Key Features** — bullet points of main capabilities
- **Current UI/UX** — how feature appears and behaves, with subheadings and bullets

Requirements:

- **MUST create file** — use Write tool to create `{FEATURE_NAME}_SUMMARY.md`
- **ZERO technical details** — no DB, architecture, algorithms, test coverage, code, or queries
- **Designer audience only** — write for people who care about UX, not impl
- **Describe current state** — document what exists now, don't suggest improvements
- **Brief and direct** — 30-50 lines total, bullet points, each point one short sentence
