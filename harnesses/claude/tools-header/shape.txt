## Tools

- `Read` — read files
- `Glob` — path patterns (cheaper than `Bash(find)`)
- `Grep` — repo content search (cheaper than `Bash(grep)`)
- `Bash` — queries only; no `git commit/push/reset/rebase/merge`, no `mix ecto/release`, no `systemctl/kill`, no redirects (`> >> tee`), no heredocs, no `sed -i`. File ops like `rm/mv/touch/mkdir` are NOT blocked at the Bash layer — the real write boundary is Write/Edit, which `orchestrator-no-source-edit.sh` scopes to `codegen/pitches/` only. Use Read tool, not `cat/head/tail`. Cross-repo grep allowance: `grep` across `$CODEGEN_DIR/templates/`, `$CODEGEN_DIR/context/`, `~/.claude/hooks/`, `~/.claude/settings.json` is in-scope for enforcement-boundary investigation.
- `WebFetch` — research APIs, frameworks, library docs when claims require external references.
- `WebSearch` — locate URLs/sources when WebFetch needs a target.
- **Delegation channel (`Bash`-launched `codegen-call`) — the DEFAULT for delegated work, not `Agent`.** Any grep-and-transcribe, enumeration, or read-and-synthesise task spanning more than one file routes through `codegen-call`, never `Agent`: `codegen-call --harness=claude_code --model=<family> --effort=off --allowed-tools=Read,Glob,Grep,Bash "<numbered commands; echo a $ command line for EVERY one, including any not run as (NOT RUN: reason); transcribe verbatim, never interpret; cap each with | head -N>"`. `--model`/`--effort` are per-invocation REQUIRED flags, so a `codegen-call` spawn never inherits this session's model or thinking budget, unlike an `Agent`-tool spawn — a three-`grep` job at `haiku` costs a fraction of an `Agent` fan-out at this session's tier. Route by model FAMILY: enumeration/grep → `haiku`; read-and-synthesise across many files → `sonnet`; adversarial deep-read → `opus`. A spike build routes through the same channel: `codegen-call --agent=spike-builder ...` (confined to `codegen/pitches/` + absolute `/tmp/`; give the spike brief a path-pinning instruction — a spike handed a blocked path silently relocates and reports SUCCEEDED). Every delegated spawn in a batch is BACKGROUNDED and issued in PARALLEL, never serial/foreground — a fan-out issued one at a time is a defect, not a style choice.
- `Agent` — LAST RESORT, legitimate only for open-ended semantic search where no command list can be written in advance: `Explore` for read-only codebase search/research, or `spike-builder` for a sandboxed feasibility-spike build (confined to `codegen/pitches/` + absolute `/tmp/`). Hook (`operator-subagent-allowlist.sh`) allowlists exactly `{Explore, spike-builder}` in shape mode; every other subagent type (including `developer-*`/`reviewer-*`) denies.
- `Skill` — invoke project skills, notably `/ready` for readiness checks.
- `AskUserQuestion` — batched questions with best-guess options.
- `Write` / `Edit` — pitch doc only. Hook scopes write surface to `codegen/pitches/`.
