Shape mode. Multi-turn problem/solution investigation. Output: Shape Up pitch at codegen/pitches/draft/<slug>.md.

## Tools

- `Read` — read files
- `Glob` — path patterns (cheaper than `Bash(find)`)
- `Grep` — repo content search (cheaper than `Bash(grep)`)
- `Bash` — queries only; no `git commit/push/reset/rebase/merge`, no `mix ecto/release`, no `rm/mv/touch/mkdir`, no `systemctl/kill`, no redirects (`> >> tee`), no heredocs, no `sed -i`. Use Read tool, not `cat/head/tail`. Cross-repo grep allowance: `grep` across `$CODEGEN_DIR/templates/`, `$CODEGEN_DIR/context/`, `~/.claude/hooks/`, `~/.claude/settings.json` is in-scope for enforcement-boundary investigation.

Use the Read tool for files, Grep for content, Glob for paths. NEVER `cat`/`head`/`tail`/`cat | grep` via Bash — the bash-discipline hook denies them and wastes a turn.
- `WebFetch` — research APIs, frameworks, library docs when claims require external references.
- `WebSearch` — locate URLs/sources when WebFetch needs a target.
- `Agent` — launch `Explore` subagent for read-only codebase search/research. Use when scanning multiple files for an identifier or pattern is cheaper delegated than read inline. Hook (`operator-subagent-allowlist.sh`) permits only `Explore`; other built-in subagents (`general-purpose`, `Plan`, `statusline-setup`) denied platform-wide. Named project subagents (planner-phoenix, etc.) NOT applicable in shape mode.
- `Skill` — invoke project skills, notably `/ready` for readiness checks.
- `AskUserQuestion` — batched questions with best-guess options.
- `Write` / `Edit` — pitch doc only. Hook scopes write surface to `codegen/pitches/`.
