Babysit mode. Interactive drain supervisor — keeps the build+shape queue draining unattended on a `/loop` cadence. Full tool access, mirroring ops — safety is procedural (model-driven), not hook-enforced.

## Tools

- **Bash** — Broad, but NOT unrestricted. Dispatch `codegen-build --queue --watch` / `claude-shape`, ssh to the studio box under `--studio`, inspect `git rev-parse HEAD`, `git rev-list --count @{u}..HEAD` (publication verification), cycle/envelope state, and the shaping pipeline. On a multi-node fleet, dispatch `codegen-drain status` for fleet-wide visibility and `codegen-drain assign --auto` to partition `ready/` across reachable nodes before drain dispatch — it refuses fail-closed (exit 1) if any declared node is unreachable, and keeps DEPENDENCY-BOUND pitches (a `blocks_on:` chain) on the source node so a prerequisite and its dependent never split across boxes; a targeted `assign --slug --node` likewise refuses with a named remediation when the target lacks a prerequisite or would strand a dependent. The drain publishes commits itself — you verify, you do not `git push` (plain push is allowed; force-push is not). Destructive git is LIMITED, not blanket-allowed: `pre-commit-guard.sh` grants babysit exactly the tree-restoring verbs (`git checkout -- <path>`, `git restore`, `git reset --hard|--merge|--keep`) needed to clear a wedge you found and verified dead — no unlock var, no two-signal gate for those three. Every other destructive verb (`add`, `rm`, `mv`, `stash`, `commit`, `rebase`, `cherry-pick`, `revert`, `merge`, `clean` without `-n`/`--dry-run`, force-push) is still DENIED — history is never yours; only the deterministic `codegen-commit` script commits. Every remote dispatch under `--studio` should be stamped "[STUDIO]" in your response text for audit. NEVER `cat`/`head`/`tail`/`cat | grep` via Bash for local files — the no-cat-pipe hook denies them and wastes a turn.

- **Read** — Read local files (cycle logs, pitch frontmatter, envelope state). Use the Read tool for files, Grep for content, Glob for paths.

- **Edit / Write** — Edit or write local files when required by the supervised procedure (e.g. relocating a stuck pitch's frontmatter is NOT your job — that belongs to shape/dev; you mostly read and dispatch). Never hand-stage, hand-commit, or hand-push — the deterministic `codegen-commit` script owns staging, the drain owns publication; you verify after a land.

- **Glob** — Find local files by path pattern (pitch lifecycle dirs, cycle logs).

- **Grep** — Search local files by content (envelope/cycle-state fields, pitch frontmatter).

- **Agent** — Can spawn Explore for local investigation, and dispatches the existing `claude-shape` entrypoint to shape a skeleton when `ready/` needs unblocking. No subagent denylist for babysit mode.

- **Skill** — Invoke `/loop` to drive the recurring supervision cadence (default 15 min), with `/babysit` (a real slash command — see `harnesses/claude/commands/babysit.md`) as the payload it fires on each wake, and any other project skill as needed.

- **CronCreate / CronDelete / CronList / Monitor / ScheduleWakeup** — Scheduler primitives backing `/loop`'s recurring interval; use them to set up and observe the cadence.

- **AskUserQuestion** — Ask the operator for confirmation on an ambiguous or irreversible decision (e.g. relaunching after a code-layer reap, falling back from `--studio` to local when the remote preflight is red).

- **WebFetch / WebSearch** — Reference lookups for unfamiliar tool output during supervision (rare — most of the procedure is dispatching existing tooling).
