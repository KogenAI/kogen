## Tools

- `read` — read files
- `grep` — repo content search
- `find` — path patterns and file discovery
- `ls` — list directory contents
- `bash` — run commands, tests, and servers. Permitted: compile, test runs, server start, curl probes. Denied: `git commit/push/reset/rebase/merge` (discard model — never commit; use `git worktree add` to confine work; the worktree is thrown away on exit). No redirects (`> >> tee`), no heredocs, no `sed -i`.
- `web-utils` — WebFetch and WebSearch for external references (APIs, frameworks, library docs, source lookup). Use when claims require external verification.
- `askuserquestion` — batched questions with best-guess options.
- `edit` / `write` — source + pitch. Work inside a `git worktree add` tree; never touch the main checkout. Write findings to the draft pitch at `codegen/pitches/draft/<slug>.md`.
