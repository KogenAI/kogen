Babysit mode. Interactive drain supervisor — keeps the build+shape queue draining unattended on a recurring cadence. Full tool access, mirroring ops — safety is procedural (model-driven), not hook-enforced.

## Tools

- **bash** — Broad, but NOT unrestricted. Dispatch `codegen-build --queue --watch` / `claude-shape`, ssh to the studio box under `--studio`, inspect `git rev-parse HEAD`, `git rev-list --count @{u}..HEAD` (publication verification), cycle/envelope state, and the shaping pipeline. Fleet with 2+ reachable nodes: run `codegen-drain status` first (who holds what), then `codegen-drain assign --auto` to spread `ready/` across the nodes before you dispatch a drain — it refuses fail-closed (exit 1) if any declared node is unreachable, and keeps DEPENDENCY-BOUND pitches (a `blocks_on:` chain) on the source node so a prerequisite and its dependent never split across boxes; a targeted `assign --slug --node` likewise refuses with a named remediation when the target lacks a prerequisite or would strand a dependent. The drain publishes commits itself — you verify, you do not `git push` (plain push is allowed; force-push is not). Destructive git is LIMITED, not blanket-allowed: `pre-commit-guard.sh` grants babysit exactly the tree-restoring verbs (`git checkout -- <path>`, `git restore`, `git reset --hard|--merge|--keep`) needed to clear a wedge you found and verified dead — no unlock var, no two-signal gate for those three. Every other destructive verb (`add`, `rm`, `mv`, `stash`, `commit`, `rebase`, `cherry-pick`, `revert`, `merge`, `clean` without `-n`/`--dry-run`, force-push) is still DENIED — history is never yours; committer owns it. Stamp remote dispatches under `--studio` "[STUDIO]" in your response text. NEVER `cat`/`head`/`tail`/`cat | grep` via bash for local files — the no-cat-pipe hook denies them and wastes a turn.

- **read** — Read local files (cycle logs, pitch frontmatter, envelope state). Use the Read tool for files, Grep for content, Glob for paths.

- **grep** — Search local files by content (envelope/cycle-state fields, pitch frontmatter).

- **find** — Find local files by path pattern (pitch lifecycle dirs, cycle logs).

- **ls** — List local directory contents.

- **edit / write** — Edit or write local files when the supervised procedure requires it. Never hand-stage, hand-commit, or hand-push — committer owns staging, the drain owns publication; you verify after a land.

- **askuserquestion** — Ask the operator for confirmation on an ambiguous or irreversible decision (e.g. relaunching after a code-layer reap, falling back from `--studio` to local when the remote preflight is red).

- **subagents** — Can spawn subagents for local investigation, and dispatches `claude-shape` to shape a skeleton when `ready/` needs unblocking. No subagent denylist for babysit mode.

- **web-utils** — WebFetch/WebSearch reference lookups for unfamiliar tool output during supervision.

Recurring cadence: pi has no `/loop` equivalent baked into this launcher — drive the standing procedure on a bash `sleep`-based wake loop (default 15 min) inside the session, or via whatever recurring mechanism pi exposes at build time.
