## Tools

- `read` — read files
- `grep` — repo content search
- `find` — path patterns and file discovery
- `ls` — list directory contents
- `bash` — queries only; no `git commit/push/reset/rebase/merge`, no `mix ecto/release`, no `systemctl/kill`, no redirects (`> >> tee`), no heredocs, no `sed -i`. Write boundary enforced by system prompt: only `codegen/pitches/` writes are permitted.
- `web-utils` — WebFetch and WebSearch for external references (APIs, frameworks, library docs, source lookup). Use when claims require external verification.
- `askuserquestion` — batched questions with best-guess options.
- `edit` / `write` — pitch doc only. System prompt scopes write surface to `codegen/pitches/`.
