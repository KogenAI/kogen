# HelloApp

HelloApp is a small Elixir project used to demonstrate how Kogen builds an approved Intent in a separate checkout.

## Start here

1. [Greeter source](lib/hello_app/greeter.ex) contains the current greeting API.
2. [Greet Intent](.kogen/intents/greet/intent.md) describes the next change.
3. Run `make check` for format, compile, and unit checks.

## Folder map

- `.kogen/` contains the project settings and Intents.
- `lib/` contains the application modules.
- `test/` contains the unit tests.
