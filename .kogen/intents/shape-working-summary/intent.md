### Investigation and technical settlement

Current `ShapeWorkingContext.prepare/5` and `RefineWorkingContext.prepare/7` encode full documentation collections and every archive reference in each reset message. Shape parses original documentation results before the existing display bound; Refine retains full documentation rows too. Thus the delivered 16384-byte tool display cut does not remove this independent recurring cost. A local current-source probe with an 82202-byte mandatory message and 42 synthetic 10035-byte documentation bodies reduced to 510496 rendered bytes. Another with 20 such records produced reset summaries of 203807 then 204069 bytes. These are synthetic reproductions of the mechanism, not proof of the entire stopped run's causality, provider retries, completion time or costs.

The selected retained archives were available read-only. Archive 50 had prefix `f623c5df1d986e1e`, archive 115 `a4cfbfc0887bc772`; both had 42 documentation results and respectively 49/114 history references. Measurement of decoded UTF-8 content/compact JSON differed from the supplied operator serialization sizes (for example archive 115: 234663 decoded summary bytes, 200579 compact documentation bytes). Keep those distinctions; do not rewrite historical claims as new live observations. Actual historical documentation bodies are not copied into public fixtures.

Implement this minimal storage/display change in both working-context owners:

1. Keep the complete in-process history list and native documentation list unchanged. Never cap the proposal/original manifest, documentation, assistant observations, authority or actual history; never deduplicate lookup occurrences. Existing native documentation progress, events, retained records, discovery checks and provenance remain intact.

Shape freezes `sh.docs`; Refine freezes `sh.working_context.documentation`, without converting one owner's native record shape to the other's.
3. The documentation reference is exactly `{path, sha256, count, format: "ndjson"}`, with an absolute custody path, lowercase SHA-256 of the complete snapshot bytes, and occurrence count. Bind it in the numbered archive's top-level `documentation` field before hashing that archive. Keep all other existing handoff state complete: manifest, ownership/frozen originals or declared steps/inspection, invalid submissions, exact readiness identity/observations and assistant observations. Retain the `Local working-window reset` label, diagnostic/not-authority warning, and a `manifest/state: ` delimiter before the JSON.
