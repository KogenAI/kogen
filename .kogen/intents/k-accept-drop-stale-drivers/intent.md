K-ACCEPT-DROP-STALE-DRIVERS (entanglement audit, finding F11; main's ruling, 3 Nov 2026). Kogen's acceptance observes only the built kogen binary from outside: CLI output, files, Git state and the fake provider's HTTP exchanges. The Go observation drivers in `features/steps/` that were mounted with `go test -overlay` onto `cli/build`, `cli/shape`, `cli/executor` and `cli/verify` call unexported internals of packages that left kogen at the 2 Nov extraction (`cli/assembly_test.go` asserts those directories are gone), so every scenario that runs one cannot pass. This change removes those drivers, every step definition and scenario that depended on them, and `cli/testdata/legacy` (a byte-identical copy of kogen-build's `build/testdata/legacy/project`). It is a refactor: no component behaviour, Kogen CLI command, flag, timeout, `cli/go.mod` or `cli/go.sum` changes.
