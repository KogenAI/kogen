# Native profile authority amendment

The first Scout pair exposed a harness defect: helper model self-report was treated as profile authority. Owned rollout `turn_context` metadata showed the requested Terra-low and Luna-low profiles actually ran, while the roots discarded otherwise substantive helper answers. Worker-Terra had begun when the defect was reported; the campaign was interrupted, its streams and fixture diff were archived, and all owned processes were reaped.

Corrected prompts contain no profile self-report field or task-level profile gate. The root returns the helper task JSON verbatim. Only runner-owned native child `turn_context` establishes actual model and effort. The corrected six-arm manifest uses fresh output paths and an independent one-shot marker; the original attempts remain evidence and are excluded from the matched comparison.
