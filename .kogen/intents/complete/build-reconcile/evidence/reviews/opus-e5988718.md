2. **The stand-in can read the hang file before the pid is in it.** (`INTENT.md:164-166`, `INTENT.md:289-291`, `INTENT.md:296-298`)
   - The fake writes its pid with a plain write, and `await_hanging!` returns "the pid in it" as soon as the file exists. A poll that lands between the file being created and the pid being written reads an empty string. Parsing that fails, or `kill -0 ""` behaves wrongly.
   - That makes the stand-in timing-dependent, which is one of your criteria.
   - Fix: have the fake write to a temp file and rename it into place, and specify that `await_hanging!` waits (still bounded at 60 s) for a non-empty, parseable pid.
