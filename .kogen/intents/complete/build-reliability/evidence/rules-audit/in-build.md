# In-Build hard stops: candidates like the GuardedPaths/.gitignore case

Scope: stops from Developer-turn end through Review and publication.
Historical cost from `plan/research/build-failure-mining-2026-09-26.md`
Appendix A (132 records, 09-10 to 09-26) and its per-Intent table; record.json
grep counts are unreliable here because these Builds are Kogen building
itself, so rule *names* appear in scenario text even on passing runs — I did
not use raw grep counts as cost evidence.

Already addressed by the build-reliability Draft (`.kogen/intents/drafts/build-reliability/scenarios.yaml`),
so **not** re-reported: offline/paid retry separation, environment vs.
provider failure classes with one retry for overload/5xx
(`environment-and-provider-classes`), `unchanged-candidate-stops`,
Jev-objection/missing-selectors reordering (`notes-and-selectors-before-verification`),
Reviewer verdict schema + one re-ask (`per-launch-verdict-schema`,
`reviewer-reask-once`), and the `.gitignore` freeze itself (`declared-gitignore-edit`,
the Shaper's own example).
