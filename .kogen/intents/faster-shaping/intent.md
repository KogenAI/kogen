One coherent SHAPE/PREPARE package combines selective context, focused-probe guidance, exact original-readiness evidence reuse and optional bounded delegation. Almir's 19 October 2026 steering supersedes the earlier separation of levers: “You cna keep together all shaping speed improvements. No need to separate and waste time that way, right?” Preserve `faster-shaping`, its useful artifacts and current guards. No additional Intent, planner, critic, per-lever shaping/review/commit cycle or generic agent/cache framework. This package is proposed work, not approval or implementation authority.

Extend native `kogen intent shape <slug> <file|->` and targeted `kogen intent refine <slug> <sha256> <file|->`. Today Shape makes one provider request at a time, embeds all tracked paths and complete step bodies, and replays accumulated tool outputs; Refine embeds all original owned artifacts and unconditionally checks the original in scratch. Keep ordinary main-provider recovery, tools, model defaults and sequential delegation behavior when workers are absent or disabled. Context selection and safe original-evidence reuse also apply without workers. Neither fanout nor a speed/quality improvement is guaranteed. Do not enable workers in this checkout's `.kogen/project.yaml`.

**Selective native context.** Replace eager unrelated complete file bodies with a deterministic source index and bounded relevant excerpts. Use existing repository reads/searches and native retained bytes, not a summarizer/critic model or generic conversation compactor. Initial Shape keeps the exact active request and Q&A, README instructions, testing rules, configured commands, protection and automatic acceptance-baseline contract. Refine keeps the exact correction, original Intent prose and Gherkin contract, declared model interface/invariants, ownership/Acceptance declarations, protection, cumulative proposal manifest and actual original/candidate observations. Preserve literal inputs and outputs, even when larger than an excerpt budget. Necessary exact contract details win over size budgets: explicitly disclose why a contract source is included in full rather than silently clipping it. A summary is navigation/evidence only; it cannot replace or amend any of these facts.

Expose a stable single-line `Context index: <JSON>` in main input. It has `{revision:{head,tree}, entries:[{path,sha256,bytes,ownership,signatures,source}], directories:[{path,count}], retrieval}`. Entries sort by path, signatures retain exact Gherkin step patterns or relevant declarations with source line ranges, and ownership distinguishes editable-owned/shared/protected/source. Source identifies frozen original or cumulative proposed bytes, never merely a model recollection. Include all current Acceptance paths, known step signatures and request-relevant source paths. Unrelated repository paths may be represented by directory counts plus `list_files`/`search_text` instead of an eager whole-tree path dump; paginate a large signature index with an explicit retrieval route and count, not hidden omission. Include indexed paths for discovered unrelated bulk fixture files but not their complete bodies. Index entries and excerpts carry exact path, revision and SHA-256; excerpts have line ranges. Select relevant excerpts deterministically from request terms, declared Acceptance and exact signature matches, default at most 80 lines/8 KiB per nonauthoritative source. Relevance is an aid, not permission to lose authoritative contracts.

Keep original bytes in existing native original/evidence state and proposals in the accumulated proposal map, with deterministic manifests including path/hash/source on every later request. No new tool family is needed. Tool results already retained in native state may be replaced in later model input by bounded excerpts and exact retrieval references, but never silently erase active request, decisions, proposal bytes or actual failure details needed to diagnose the current candidate. Include current actual readiness observations and their exact retained reference; do not substitute a summary claiming green.

**Dispatch interface.** `shape_batch({brief,jobs})` requires 1–3 jobs with unique IDs and a complete common brief. `brief` has `revision:{head,tree}`, nonempty `outcomes`, `interfaces`, `transitions`, `fixtures`, `exclusions`, `protected_paths` array and `artifacts` array of `{path,expectation}`. Outcomes/interfaces preserve literal requested inputs; transitions states invariants or explicitly stateless; fixtures names runner/tool/data prerequisites and baseline expectations; exclusions states authority limits. Protection covers configured and automatic baseline paths. Artifacts explains agreement across prose, Gherkin, steps and justified Quint. Empty arrays are allowed only when genuinely empty, not substitutes for boundaries.

Each job is `{id,role,scope,paths,owns}`: role read/probe/draft, scope a nonempty exact independent task, paths inspect scope and owns exact draft file list. Read/probe owns is empty; draft owns is nonempty, confined to this Intent/configured step folder and existing submission protections. Inspect scopes can overlap; draft ownership is disjoint across the batch. Normalize aliases and reject traversal, directories, symlink escapes, duplicate/ancestor-overlapping ownership and protected targets before provider calls. Missing brief/boundary, invalid size, stale revision or ownership conflict returns `{status:"refused",reason:<nonempty diagnostic>,jobs:[]}`, starts no workers and changes no proposals. Stay sequential until complete boundaries can be supplied; do not invent a brief.

Expose current `{head,tree}`: full Git HEAD and temporary-index snapshot of tracked/untracked nonignored content excluding `.kogen/local`, without altering real index (reuse Snapshot/Git). Check at dispatch and before returning usable drafts. Drift invalidates drafts truthfully without redispatch. Each worker's first user content is JSON encoding `{brief,job}`; no need copy main/sibling private transcripts. Scope is a task boundary, not a new filesystem sandbox; preserve existing read traversal and safe scratch containment/isolation.
