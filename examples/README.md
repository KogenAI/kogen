# Kogen examples

This folder contains the small real-use project used to qualify REL-1.

Start with [Tiny Tasks](tiny_tasks/README.md). Its fixed feature request is
[FEATURE-REQUEST.md](tiny_tasks/FEATURE-REQUEST.md), and its independent
acceptance qualification is [tiny_tasks-qualification/README.md](tiny_tasks-qualification/README.md).

| Path | Purpose |
| --- | --- |
| `tiny_tasks/` | Plain-Elixir task list used by the live real-use run |
| `tiny_tasks-qualification/` | Acceptance feature, reference and deliberately incorrect patches, and the qualification script |
