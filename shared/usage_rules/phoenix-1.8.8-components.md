# phoenix - Components & Templates

## Function Components

Function components are the foundational building blocks for markup rendering in Phoenix. They accept an `assigns` parameter and return a HEEx template. Components work across MVC controllers, LiveView applications, layouts, and custom UI definitions.

### Basic Structure

A function component requires attribute declarations and a template definition:

```elixir
defmodule HelloWeb.Greeting do
  def greet(assigns) do
    ~H"""
    <h2>Hello {@messenger}!</h2>
    """
  end
end
```

With explicit attribute declarations for validation:

```elixir
defmodule HelloWeb.Card do
  attr :title, :string, required: true
  attr :content, :string, required: true
  attr :class, :string, default: "card-default"

  def card(assigns) do
    ~H"""
    <div class={@class}>
      <h3><%= @title %></h3>
      <p><%= @content %></p>
    </div>
    """
  end
end
```

### Component Invocation

From the same module (typically CoreComponents):

```html
<.greet messenger="World" /> <.card title="Welcome" content="Hello!" />
```

From different modules:

```html
<HelloWeb.Greeting.greet messenger="Alice" />
<HelloWeb.Card.card title="Info" content="Details..." />
```

With slot content:

```html
<.modal title="Delete?">
  Are you sure? <button>Delete</button>
</.modal>
```

## HEEx Template Language

HEEx ("HTML + Embedded Elixir") provides safe HTML templating with embedded Elixir expressions.

### Interpolation & Escaping

Simple interpolation is escaped by default to prevent injection:

```html
<p><%= @message %></p>
<!-- Safe: HTML entities are escaped -->
```

Raw unescaped output (use carefully):

```html
<div><%= raw(@html_content) %></div>
```

Safe raw output preserves intentional HTML:

```html
<div><%= @safe_html %></div>
<!-- Use when @safe_html is generated by the framework -->
```

### Attribute Handling

Dynamic attributes:

```html
<input type="text" value="{@value}" disabled="{not" @enabled} />
```

Spread keyword lists:

```html
<input {@input_attrs} />
<!-- @input_attrs: [type: "text", placeholder: "Enter..."] -->
```

Special attribute handling (`:if`, `:for`):

```html
<div :if="{@show_banner}" class="banner">Important!</div>
<.card :for={item <- @items} item={item} />
```

### Control Flow

Conditional rendering:

```html
<%= if @user do %>
  <p>Welcome, <%= @user.name %>!</p>
<% else %>
  <p><a href={~p"/login"}>Log in</a></p>
<% end %>
```

Iteration:

```html
<ul>
  <%= for post <- @posts do %>
  <li><%= post.title %></li>
  <% end %>
</ul>
```

## Layout System

Phoenix uses a hierarchical layout system for consistent page structure.

### Layout Hierarchy

**Root layout** (`root.html.heex`): Contains HTML document structure:

```html
<html>
  <head>
    <meta charset="UTF-8" />
    <title>My App</title>
  </head>
  <body>
    {@inner_content}
  </body>
</html>
```

**App layout** (`app.html.heex`): Wraps page-specific content with navigation:

```html
<header><nav>Home | About</nav></header>
<main>{@inner_content}</main>
<footer>© 2024</footer>
```

**Page templates**: Inject content into layouts:

```html
<.heading>My Page</.heading>
<p>Content here...</p>
```

Connect layouts in controllers:

```elixir
def home(conn, _params) do
  render(conn, :home, layout: {HelloWeb.Layouts, :app})
end
```

### Creating Custom Layouts

Add functions to `Layouts` module:

```elixir
defmodule HelloWeb.Layouts do
  use HelloWeb, :html

  def admin(assigns) do
    ~H"""
    <div class="admin-wrapper">
      <aside><.admin_menu /></aside>
      <main>{@inner_content}</main>
    </div>
    """
  end
end
```

Use in controllers:

```elixir
render(conn, :dashboard, layout: {HelloWeb.Layouts, :admin})
```

## Best Practices

- **Component reuse**: Create a `CoreComponents` module for application-wide UI building blocks (buttons, forms, modals).
- **Attribute declarations**: Always declare expected attributes explicitly; this enables validation and improves IDE support.
- **Template readability**: Use HEEx shorthand (`:if`, `:for`) for cleaner, more concise templates.
- **Escape user input**: Never use `raw/1` with untrusted data; let Phoenix handle escaping automatically.
- **Slot usage**: Use slots for flexible content composition instead of passing HTML strings.
- **Layout organization**: Keep layouts minimal; move complex logic into components.

## Form Components

Phoenix provides form helpers for safe form generation:

```html
<.form :let={f} for={@changeset} action={~p"/posts"}>
  <.input field={f[:title]} type="text" label="Title" />
  <.input field={f[:body]} type="textarea" label="Body" />
  <:actions>
    <.button>Save</.button>
  </:actions>
</.form>
```

The form component automatically includes CSRF tokens and binds errors to fields.
