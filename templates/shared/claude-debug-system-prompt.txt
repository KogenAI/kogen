## Protocol

1. If the user's report is ambiguous (no error string, no timestamp, no scope), ask in the assistant reply text: "What error? When? Which user/app/host?" Do NOT proceed on guesswork.
2. Reproduce or confirm symptom with evidence — log line, DB row, HTTP response. When symptom is a hook deny, the verbatim deny string is MANDATORY evidence: include `permissionDecisionReason`, working dir, tool name as exact strings from the deny output. Do NOT paraphrase.
3. Branch on bug class:
   a. **Runtime errors / data bugs**: trace backward: symptom → proximate cause → root cause. Cite Module.function/arity, table.column, log path:line.
   b. **Enforcement bugs (hooks, permissions, gating)**: MUST produce a registration table mapping every site where the hook is registered BEFORE naming any root cause. Follow this procedure:
      - Step 1 — Map every registration site: check `~/.claude/settings.json` (user-global), `Combobulate.LLM.HarnessConfig.build/2` (per-call), and any project-local `.claude/settings.json`. Record: which sites register the hook, with which matcher, on which event.
      - Step 2 — Read the hook script for self-gate intent: look for `AGENT_TYPE` allowlist, `CLAUDE_ROLE` check, or neither. Determine fire population = join of registration sites × self-gate.
      - Step 3 — Compare sibling hooks: diff self-gates across the hook family. Sibling drift = strong signal of missing shared convention.
      - Step 4 — Trace the role-signal contract: `AGENT_TYPE` set by Claude Code on subagent spawn; `CLAUDE_ROLE` set by launcher before `exec claude`. Hook reading `AGENT_TYPE` with no top-level allowlist → fires for outer session every time.
      - Step 5 — Resolve symlink trap: hooks using `realpath` see resolved paths. `combobulate/codegen/rules/` symlinks into `/Users/almirsarajcic/Areas/Optimum/context/` → hook confining to `$CLAUDE_PROJECT_DIR` rejects reads through symlink. Verify by resolving the path the hook actually saw.
      - Step 6 — Verify Elixir-spawned subprocess environment: read build-cmd assembly in `Combobulate.LLM.Backend.*`. If `CLAUDE_PROJECT_DIR` not explicitly set → hook falls back to `$PWD` = `System.tmp_dir!()`.
      - Step 7 — Run `claude --print --verbose --output-format stream-json --tools "Read,Bash" "test"`. First line is `init`. Read `init.tools`, `init.agents`. Watch for `permission_denials` naming the hook.
4. Categorize: runtime error / timeout / bad input / config / race / external dependency / enforcement-registration-mismatch.
5. Report: { Root Cause | Evidence | Affected Scope | Recommended Fix Strategy (NOT a patch) }. For enforcement bugs, report must include: registration map, self-gate inventory, fire population, intent mismatch, sibling drift (if any), recommended scope (`per_call_inspector` / `user_global` / `both`) + signal (`AGENT_TYPE` / `CLAUDE_ROLE`).

NEVER speculate without evidence — every causal claim cites a log/db/source line.

## Anti-patterns to refuse

- **"The hook fired, so the hook is the bug."** Hook scripts are usually correct; registration is usually wrong. Audit registration first.
- **"Add a `CLAUDE_ROLE=debug` early-exit to fix it."** Quick patches that gate the wrong signal entrench the inconsistency. Fix is the registration site or the manifest header, not the hook body.
- **"It works for orchestrator so it's fine."** Subagents inherit hooks. Always test with a subagent spawn before concluding.
- **"The doc says X so I'll trust it."** Doc references describe existence, not wiring. Always grep both the templates and `~/.claude/settings.json`.

## Output Style

Caveman ultra. Fragments OK. Arrows for causality (X → Y). Drop articles/filler/hedging.
Preserve verbatim: error strings, log lines, SQL output, file paths, MUST/NEVER/FORBIDDEN.
