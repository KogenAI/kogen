---
description: Create a feature summary document for designers and stakeholders
---

Analyze the current feature implementation and create a clear, concise markdown summary document for sharing with designers and product managers.

Document structure (exactly these sections):

- **Summary** - Short paragraph describing what the feature does from a user perspective
- **Key Features** - Bullet points of main capabilities and functionality
- **Current UI/UX** - How the feature appears and behaves, with subheadings and bullets

Requirements:

- **MUST create a file** - Use Write tool to create `{FEATURE_NAME}_SUMMARY.md` in current workspace
- **ZERO technical details** - No database, architecture, algorithms, test coverage, code, or queries
- **Designer audience only** - Write for people who care about user experience, not implementation
- **Describe current state** - Document what exists now, don't suggest improvements
- **Brief and direct** - 30-50 lines total, use bullet points, keep each point to one short sentence

Focus on:

- What the feature currently does for users
- How users currently interact with it
- The current visual and behavioral state

This creates a shareable artifact for designer collaboration, team onboarding, and future feature planning.
